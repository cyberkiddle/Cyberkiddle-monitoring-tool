🆘 TROUBLESHOOTING:

Problem: "ModuleNotFoundError: No module named 'llama_cpp'"
Solution: Run "bash setup.sh" or "pip install llama-cpp-python"

Problem: "Model not found"
Solution: Check /home/cyberkid/bin/Ai/models/ directory

Problem: Very slow responses (>30 seconds)
Solution: Use smaller model or reduce max_tokens

Problem: Out of memory
Solution: Use 3B model instead of 7B, reduce n_ctx

Problem: Port 5000 already in use (web_chat.py)
Solution: Modify port in web_chat.py (search for port=5000)
