⚙️ CONFIGURATION:

Edit these files to customize:
  • chat.py (line ~24): Model parameters
  • chat.py (line ~35): Response generation settings
  • advanced_chat.py: Similar configurations

Key parameters:
  • n_ctx: Context window (2048 default)
  • n_threads: CPU threads to use
  • max_tokens: Response length
  • temperature: Creativity vs focus (0.0-1.0)
  • n_gpu_layers: GPU acceleration (0 = CPU only)

🆘 TROUBLESHOOTING:

Problem: "Model not found"
  Solution: Check models are in /home/cyberkid/bin/Ai/models/
  Run: python3 chat.py list

Problem: "ModuleNotFoundError: No module named 'llama_cpp'"
  Solution: Run setup.sh or pip install -r requirements.txt

Problem: Very slow responses
  Solution: Use smaller model (Orca Mini) or reduce max_tokens

Problem: Out of memory
  Solution: Reduce n_ctx value in chat.py or use 3B model
